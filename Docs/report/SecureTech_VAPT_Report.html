Generated 2026-10-27 05:30 UTC. Simulated organization. Lab environment only.

1. Executive summary

SecureTech Solutions was assessed as a simulated 60-employee organization. The assessment found 24 open technical findings, of which 15 are priority P1 or P2. The security posture score is 33/100 (Critical). Compliance status: 7 of 8 control areas are non-compliant and 1 are partially compliant.

The most urgent actions are to remove the vsftpd 2.3.4 backdoor, fix the SQL injection on the employee web portal, and disable or restrict the VNC, rsh, rlogin, X11, Samba and AJP services. Anonymous FTP, Telnet and password-free sudo have already been fixed on the company server.

5. Risk method

Each finding is scored with CVSS v3.1 base metrics. The vector for each finding is listed in the evidence folder. Risk = CVSS base score x (asset criticality / 5) x exposure factor. Exposure factor: Remote 1.0, Internal 0.8. CVSS already includes how easy the attack is, so no separate exploitability factor is applied, which avoids counting it twice. Priority: P1 at 7.0 or above, P2 at 5.0 or above, P3 at 3.0 or above, P4 below 3.0. Likelihood and impact (1-5) are recorded for each finding but are not part of the formula.

Posture = 100 x (1 - open risk / total maximum risk). Each finding's risk is its CVSS v3.1 base score x (asset criticality / 5) x exposure factor. Its maximum is CVSS 10 on the same asset. Resolved findings still count toward the maximum, so fixing a finding raises the score. This is a prototype indicator, not a certified security rating.

9. Limitations

  • This is a lab assessment of a simulated organization. Findings are not a certified rating.
  • CVSS v3.1 base scores are computed from each finding's vector. The vectors for the scanner-found services are assessments (see Docs/risk_scoring.md, section 1.2), not NVD entries for the exact versions detected.
  • Web testing used Nmap HTTP scripts and curl. OWASP ZAP and Burp Suite were not used.
  • The company server is intentionally vulnerable and is isolated from other networks.
